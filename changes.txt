CHANGELOG
=========

Commit: d52e925 — Synchronize the game flow and helper functions

This commit replaces the outdated versions of `main.py` and `methods.py` with matching implementations. The notes below describe the committed code, not proposed changes.

`main.py`
--------

- **Imports and startup:** Uses `import methods` and starts the game only when run directly (`if __name__ == "__main__"`). This avoids prompts and game execution when another module imports `main.py`.
- **Player character:** Rebuilt `VideoGame` initialization so the supplied health, name, level, stats, coins, attack power, and defense are stored. Added damage, attack, and readable character display behavior.
- **Reusable character creation:** Added the top-level `create_character_instance()` function outside the classes. It prompts for name, level, strength, and speed, validates input, retries or exits, and returns a configured `VideoGame` instance.
- **Adventure flow:** Added dedicated functions for yes/no prompts, combat, reward application, shop visits, encounters, and the rest-stop menu.
- **Path selection:** Validates the player's selection and chooses the Skeleton or Crystal Dragon encounter based on the randomly assigned Skeleton path.
- **Chest and rewards:** Uses the reward returned by `methods.open_chest()` and applies supported coin, health, strength, and stat rewards.
- **Kyle Walker encounter:** Routes the encounter through the same fight-or-flee flow used for the other monsters.

`methods.py`
------------

- **Module dependencies:** Removed the circular import of `main.py`; the helper module now relies on the standard library.
- **Shared game data:** Defines flee probabilities, shop options, chest contents and weights, and monster instances in one place.
- **Monster behavior:** Added a `Monster` class with damage handling, attack power, and readable display behavior.
- **Chest opening:** `open_chest()` validates its inputs, selects a weighted drop, prints it, and returns the selected reward.
- **Fleeing and paths:** `flee_attempt()` validates the monster/probability and decrements `lives` after a failed escape. `choose_path()` validates options and returns numbered paths.
- **Shop and character helpers:** `shop()` returns purchase details when accepted; `save_character()` safely appends character data to a UTF-8 file; `access_attribute()` validates and displays a character stat.
- **Input normalization and errors:** Added the reusable `formatted()` helper and defined `ListError` as a normal `ValueError` subclass.

Formatting note: line references are omitted because this changelog summarizes a full-file replacement and line numbers can shift as the code evolves.
