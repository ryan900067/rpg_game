# rpg_game
An RPG game that is 100% based on text and uses advanced features.
Features of the game:
Admin commands 
1v1 battle scenarios
Rewards
Character saving
Code Elements:
Classes
Data Handling
File Writing
Lambda
Helper Modules
Biomes
NPCs
Special Monsters for each biome
Progression
Eight randomized encounters per run, followed by the final boss
Wood, silver, and gold chests that spawn at random
Random exploration events between battles, with optional risks and rewards

Groq-powered features:
- NPC personality generation
- Monster tactical decisions
- A new campaign opening and five-sentence scene narration for each run

















HOW TO INSTALL PANDAS:
Check if pip is installed: python3 -m pip --version
Install pip: python3 -m ensure pip --upgrade
Install pandas: pip/pip3 install pandas
OR:
Download requirements.txt and paste in VSCODE
Run: python3 -m pip --version
Run: python3 -m ensure pip --upgrade
Run: pip/pip3 install requirements.txt
